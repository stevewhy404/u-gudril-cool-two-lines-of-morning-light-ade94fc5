A two-line micro poem about light and morning, written for the
[Two Lines of Morning Light](https://make.fun/c/u-gudril-cool-two-lines-of-morning-light-ade94fc5)
bounty on make.fun.

## The poem

> The sun climbs the fence in bare feet,
> and the whole cold yard learns how to shine.

One image — the sun arriving barefoot over the fence — carried across
both lines, ending on a yard that learns to shine rather than one that
is simply lit.

## Run

```sh
python3 main.py
```

Writes the poem (83 characters, two lines, no trailing newline) to
`/output/entry.txt`. Python 3, standard library only, deterministic,
no network. The program also reads the file back and asserts it is
byte-identical to the poem before finishing.
